# DoJa to MIDP Core

本專案系個人進行 DoJa 2 MIDP 工作的封裝和工具。

## 緣起

為什麼會有這個專案？

因為個人不時會進行 DoJa 遊戲的『封裝式』移植。

所謂封裝，就是在不重寫全部遊戲邏輯的前提下，使用一層『轉接層』把 DoJa API 翻譯為 MIDP API。

這樣的好處是方便簡單，壞處則是『對專案的弱掌控』和『大量重複程式碼』。

好吧，因為後者，就產生了這個庫。


## 開源

為什麼要開源這種垃圾的 Vibe 程式碼？

程式碼確實不是我寫的，它來自 5.6 Sol；架構，文檔，註釋，測試 則是來自我。

準確地說，我負責了寫程式碼之外的所有工作。

因為這只是興趣，更新毫無穩定的時間節奏。

我只能在自己感興趣的遊戲上把它做到盡善盡美，這也是我關閉 ISSUE 的原因之一……

不過，OPEN 始終是有意義的，即便我已經預料到會因此產生垃圾。


## 垃圾

哦，就是未經完整測試，無法、或者在真機上工作不暢的那種『移植』。

現在它們或許不是，但我非常確信：

在 OpenDoJa For Android 正式發佈後，這些『移植』都會變成真正的垃圾。

因此，該 Runtime Wrapper 的基本優化準則是 **適配 S60V3 的真機**。

使用 VIBE 生成程式碼或者進行其他，都會引來非議……我對此無能為力，也不想去做沒有意義的爭論，只能說：

**本專案由 LLM 生成，實作細節均來自 DoJa API 官方文檔或是逆向工程 + 測試修補，未參考任何其他專案。**
